## Observed issue

Record the exact symptom, when it began and any error message. Separate what was observed from a suspected explanation.

| Date / time / timezone | Observation or action | Person / team reference | Result | Next step |

| | | | | |

## Investigation

- What was expected?
- What actually happened?
- Which users, devices and services are affected?
- What changed before the symptom appeared, if known?
- Which checks were completed and what did each show?
- What remains unconfirmed?

## Response and escalation

Record approved actions, responsible owners, the escalation route and any user communication. Preserve evidence in the approved internal location; include only a restricted reference here.

## Outcome

State whether service was restored, a workaround was provided or technical follow-up remains open. Record the verification check and user confirmation where relevant.
