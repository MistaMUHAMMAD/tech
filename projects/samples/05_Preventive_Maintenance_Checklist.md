## Device and workplace checks

- [ ] Confirm the device ID and record existing damage or user-reported problems.
- [ ] Check power connections, ventilation and external condition.
- [ ] Check available storage and relevant health warnings.
- [ ] Confirm approved operating-system and application updates.
- [ ] Check the organisation's endpoint-protection status.
- [ ] Check required workplace applications and peripherals.
- [ ] Check network connectivity and access to approved resources.
- [ ] Verify backup status where the device is within the backup scope.
- [ ] Record maintenance needs, replacement requirements and responsible owners.
- [ ] Confirm normal user tasks still work after approved changes.

## Handover

Record changes made, unresolved faults, the next review date and any user acknowledgement. Do not open hardware, remove software or change security settings without the relevant authorisation.
