## Onboarding

- [ ] Confirm the approved start date and access request with the manager.
- [ ] Record the assigned device ID, serial number and condition.
- [ ] Apply approved updates and check required workplace applications.
- [ ] Create or request the approved account through the authorised administrator.
- [ ] Confirm the email account and approved software licences are available.
- [ ] Provide only the access approved for the role.
- [ ] Help the user complete the organisation's MFA setup where applicable.
- [ ] Test sign-in, email, printing and required shared resources with the user.
- [ ] Explain how to request support and report suspicious messages.
- [ ] Record the handover and obtain acknowledgement.

## Offboarding

- [ ] Confirm the authorised last-access time and responsible approver.
- [ ] Arrange ownership/retention of work records under the organisation's policy.
- [ ] Request or perform approved account disablement and session revocation.
- [ ] Remove role-specific application and shared-resource access as authorised.
- [ ] Collect devices, peripherals and access items; record condition and device IDs.
- [ ] Record unreturned items and assign a follow-up owner.
- [ ] Update the asset register and approved licence records.
- [ ] Confirm completion with the manager and record unresolved actions.
