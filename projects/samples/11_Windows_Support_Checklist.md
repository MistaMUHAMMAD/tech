# Windows support checklist

Portfolio Sample | Muhammad Musa | October 2026

Demonstration template. No employer records or real user data.

## Ticket record

Record device ID, Windows version where relevant, symptom, exact error, affected application, first occurrence and recent changes reported by the user.

## Initial checks

- [ ] Confirm power, cable and peripheral connections.
- [ ] Confirm whether the problem affects one device or multiple users.
- [ ] Check the relevant application and available storage.
- [ ] Record network status where the task requires connectivity.
- [ ] Check whether the account has approved access to the required resource.
- [ ] Review relevant error messages and existing service records.
- [ ] Check approved update/restart status, with the user's work saved first.
- [ ] Make only appropriate authorised changes and record them.

## Verify and close

- [ ] Reproduce the original user task after the change.
- [ ] Confirm the outcome with the user.
- [ ] Record what was checked, changed and left unresolved.
- [ ] Escalate persistent or security-related symptoms with useful evidence.
